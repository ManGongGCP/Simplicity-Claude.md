# CLAUDE.md — Universal Operating Principles for AI Collaboration

This is my global [CLAUDE.md](https://docs.claude.codes/zh-CN/claude-code/claudemd) that applies to **every project** I work on with Claude Code.

## What's in it

- **First Principles thinking** — break every problem down to fundamentals
- **Andrej Karpathy's principles** — think before coding, simplicity first, surgical changes, goal-driven execution
- **Default workflow** — understand → clarify → plan → execute
- **Permanent rules** — no unrequested features, always consider edge cases

## Why share this

CLAUDE.md is the most impactful configuration file for Claude Code — it defines how Claude collaborates with you. A well-written one can 10x your productivity. I'm sharing mine so others can use it as a starting point.

## How to use

Copy `CLAUDE.md` to `~/.claude/CLAUDE.md` (global, applies everywhere) or to `CLAUDE.md` in any project root (per-project override).

```bash
cp CLAUDE.md ~/.claude/CLAUDE.md
```
